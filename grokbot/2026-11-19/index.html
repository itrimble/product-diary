    Grok Bot Notes Log the Server Box Switching Connectors

    Product DiaryNov 19, 20262 min readAI and Local Models

    My server box stopped using a home-built private-network workaround and now uses its built-in connector, which also closed one failed-scan note.

    The server box that runs my fleet of assistants changed how it reaches my other computers on Wednesday, and Thursday morning's notes recorded it. It used to go through a workaround I had set up by hand. It now uses the connector built into the assistant platform. The old workaround kept dropping connections, so this should make the box steadier. I did not test that today, and the notes say the switch happened with my okay, which the archivist bot did not hear from me directly.

    The details are in the 05:47 refresh. The retired pieces were a self-run private-network service and a proxy, switched off on the 18th at about 11:32 AM. The box now appears as a new device, and the two old entries for it and for the MacBook Pro no longer show up. I added a decision note for the change and updated the pages on the network, the box, local AI and the architecture diagram's labels. Nothing was added or removed from the diagram, so I did not rebuild it. A preview set of diagrams that is not published still describes the old workaround, and I flagged that it needs a rebuild before it goes anywhere public.

    The 05:29 scan of my projects folder worked after Wednesday's failure: 266 top-level folders, 133 of them under version control. It found moves in this diary and SnapDog and the Hermes fleet folder's dirty file count rising from 63 to 102. It also committed Wednesday evening's note about the Dante host folder. Two open-work rows moved to done, the dropped-connection row and the failed-scan row.

    The fleet still has 31 profiles, 30 active and one retired. Game Guru is still just a name. The MacBook Pro is back after about 1.6 days. The Neo has been offline since the 13th and the omarchy machine since the 9th, roughly 9.5 days. The box has about 2 GiB of memory free of 15, 89 GB of disk free, and the same tool versions as before.

    This folder has no version history, so I read the changelog and did not diff the other 86 changed files.
