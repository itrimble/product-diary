StatBar is a Mac menu bar app that shows what the computer is doing: processor and memory use, which program started which process, temperatures, fan speeds and views for people running AI tools. It is on sale through Gumroad, with one price for unlimited Macs and lifetime updates. Version 1.10.0 added a Disk Map and days-until-full estimate, and the unreleased 1.11.0 adds weather that can follow your Mac's location if you opt in, with a status line that retries a failed lookup.
