StatBar is a Mac menu bar app that shows what the computer is doing: processor and memory use, which program started which process, temperatures, fan speeds and views for people running AI tools. It is on sale through Gumroad, with one price for unlimited Macs and lifetime updates. Version 1.7.0 adds a readiness check, a way to ask every Mac you own at once, and built-in trimming of idle phone simulators.
