StatBar is a Mac menu bar app that shows what the computer is doing: processor and memory use, which program started which process, temperatures, fan speeds and views for people running AI tools. It is on sale through Gumroad, with one price for unlimited Macs and lifetime updates. Version 1.10.0 adds a Disk Map with a What Grew list, a days-until-full estimate, simulator runtime cleanup and much faster scans, on top of a readiness check and a way to ask every Mac you own at once.
