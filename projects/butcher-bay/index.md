Butcher Bay is the 2004 Xbox game The Chronicles of Riddick: Escape from Butcher Bay, translated ahead of time so it runs as an ordinary Mac program. On this Mac it compiles its own copy, plays the Universal logo and reaches the cell block at about sixty frames a second, while the Linux desktop still crawls through gameplay with the characters unlit. It is an experiment on my own hardware, using the same toolkit as the PlayStation 3 conversions.
