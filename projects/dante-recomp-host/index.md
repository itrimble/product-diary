Dante Recomp Host is a Mac build of a PlayStation 3 game, made with a toolkit that translates the console's machine code into source files a Mac can compile. It is an experiment on my own hardware. The game now boots to the title screen, menus and gameplay, with a graphics settings page inside the game's own options menu and a startup that reaches the first battle 47 seconds sooner, but no automated run has finished a level yet.
