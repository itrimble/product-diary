OS Pi is a classic-Mac-style desktop I wrote from scratch for the Mac, the Raspberry Pi and plain Linux. It is not Mac OS 9 and contains no Apple ROM. It runs old adventure games far enough to save, quit, relaunch and reload the same scene, proven pixel for pixel with the first Monkey Island in November, and a clean-room PowerPC runtime is under construction toward software from the later Power Mac era. Music in a game's opening seconds still sounds doubled, which is the open problem.
