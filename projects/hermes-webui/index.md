Hermes WebUI is a browser front-end for the Hermes agent that runs my house assistant: chat and sessions, a workspace file browser and settings, served privately on my tailnet and reachable from my phone. It is upstream open-source software deployed unmodified on the mini, so entries here are about running it, not writing it. It went live on 25 October 2026 behind a generated password, and is not yet set up to survive a reboot.
