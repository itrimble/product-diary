    Hisense TV Tune-up

    This project combines a repair log for a Hisense Android television with an experimental podcasts app and a lightweight home-screen launcher. The app has a native cached library for Apple and private Club TWiT shows, while Apple sign-in and playback still use the web player. Reviewed application source is publicly available; private household notes and account data are excluded.
