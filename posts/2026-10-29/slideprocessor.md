Lectern, my app that turns slide decks into lecture notes, did not change on Thursday. What changed is what I plan to say about it. While writing a new batch of advertising, I found that my own project notes undersell the app: the version on the Mac App Store does more than the README claims, and the ads have to be built from the store, not from the notes.

The new file is `marketing/ads/native_sales_ads_2026-10-29.md`, 202 lines, in one commit. It opens with a table of corrections. The store has version 1.2, released on 18 August, not the 1.1 the README names. It imports Word, classic PowerPoint, Excel, OpenDocument, RTF, EPUB and CSV on the Mac itself, with no upload, and it ships in 12 languages. A new helper borrows a second provider's vision model when your chosen one cannot see images. Scanned-PDF text recognition is optional and sits behind a disclosure.

The test count was also wrong. The README says 48 cases in one place and 16 in another. The registry holds 115.

The rule in the file is just as useful. Every ad must say Apple Silicon only, macOS 14 or later, because every release script builds for that one chip. There are no store ratings yet, so no rating claims. A presenter mode with recording turned up in an August audit, but it is not in the shipped release notes, so it is off limits.

I read the file; I did not check the store page myself tonight, and I did not run the app.
