title: SnapDog's Recording Focus Fix Is Still Unfinished
summary: The recording focus fix is still unfinished, and the product site gained new pictures of the order page.
---
SnapDog users saw no change on 2 October. The fix that stops a screen recording from eating your first click, which I wrote up on 30 September, is still half done on the Mac mini. The only visible movement was on the product site, which picked up new pictures of its order page.

A survey flagged the project because it had uncommitted work. Looking at when the files were saved, the picture is calmer than that sounds. The three files behind the focus fix were last touched around 22:35 the night before: the new helper, the edit to the recording manager, and a test file with three tests for the question of which app should get control back. I have not run those tests, and nothing is committed.

The new site images are a plain shot of the order page and an annotated copy, both saved about 11:30 the previous morning. They sit beside older images of the editor and the filtered history view.

So the focus fix stood where it stood on the 30th: written, saved, untested and uncommitted. A day that moves nothing forward is still worth a line in a diary, if only so the next entry does not pretend it did.
