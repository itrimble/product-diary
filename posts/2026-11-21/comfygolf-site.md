Comfy Golf now has a home on the web. There is a landing page, a short guide that explains how to play, and a demo you can try in the browser without installing anything. Until Saturday the game only existed as a project folder, so this is the first time anyone outside my desk can see what it is.

The site is deliberately small. It is plain pages plus one bundled script for the demo, a dark theme with a single green accent, and a few tiny looping clips with poster images so the page does not look empty before the video loads. The guide opens with a short lede, then numbered steps and a controls table that uses keyboard-key styling, which I prefer to a wall of prose.

It is set up for GitHub Pages: a marker file stops the host from treating the folder as a Jekyll site, and there are icons in four sizes plus a touch icon for phones. All of it landed as one commit.

What I did not do: test the demo on a phone, or on any browser except the one that took the screenshot. The clips are under 9 kilobytes each, so they are more mood than footage.
